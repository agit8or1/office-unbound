# Office Unbound third-party software inventory

Status as of 2026-11-15. Required by ADR-0007 before adoption. Gate = ADR-0007 component gate (source available; self-hostable; commercial use permitted; no per-user licensing; no connection caps; no mandatory subscription or external API; independently maintainable; portable customer data; unrestricted growth). Unclear license = not adopted.

Gate key: PASS = meets gate. PASS-with-obligations = meets gate if listed duties are kept. UNCLEAR = not adopted until resolved. FAIL = not adopted as found. "Lab only — not shipped" = used only in the lab, never in a shipped artifact.

Conventions: "OU-UNASSIGNED" = no Office Unbound maintenance owner is named in any source report. "UNVERIFIED" = the source reports did not verify this item. Versions come from `blueprints/lab/common/versions.env` and `ics/requirements.txt` unless stated otherwise. Licences for Python packages come from installed metadata (`ics/.venv`).
