# Office Unbound third-party software inventory

Status as of 2026-11-15. Required by ADR-0007 before adoption. Gate = ADR-0007 component gate (source available; self-hostable; commercial use permitted; no per-user licensing; no connection caps; no mandatory subscription or external API; independently maintainable; portable customer data; unrestricted growth). Unclear license = not adopted.

Gate key: PASS = meets gate. PASS-with-obligations = meets gate if listed duties are kept. UNCLEAR = not adopted until resolved. FAIL = not adopted as found. "Lab only — not shipped" = used only in the lab, never in a shipped artifact.

Conventions: "OU-UNASSIGNED" = no Office Unbound maintenance owner is named in any source report. "UNVERIFIED" = the source reports did not verify this item. Versions come from `blueprints/lab/common/versions.env` and `ics/requirements.txt` unless stated otherwise. Licences for Python packages come from installed metadata (`ics/.venv`).

## Open license questions (for counsel)

1. **Gromox mixed licence.** 147 files are GPL-2.0-only WITH a linking exception (Steep-derived, `LICENSE.txt` l.1260-1270), Samba-derived files are GPLv3, the rest AGPL-3.0. Is the exception broad enough for combined binaries and modified versions? (groupware-source-eval §12.1)
2. **Trademarks.** Are "grommunio", "gromox" and the logo registered marks of grommunio GmbH? Can a fork use `gromox-*` and `grommunio-*` package names, or must it obtain written permission? The legal notice text was not retrieved. (groupware-source-eval §12.2; groupware-eval §1.3)
3. **Ext JS 3.4 (GPL-3.0-only) and Ext.ux Metaform (LGPL-3.0 with an unclear "commercial use permitted" sentence)** inside an AGPL-3.0-or-later web app: section 13 compatibility. (groupware-source-eval §12.3)
4. **Admin-api 5-user cap.** Is removing or bypassing the licence check acceptable under the copyright licence alone? Could the GTC (May 2026) or a partner or subscription agreement add restrictions? Whether the cap is technical or terms-only is UNVERIFIED. More than 5 mailboxes on community is a "grey area" per groupware-eval §1.3. (groupware-source-eval §12.4)
5. **AGPL section 13 source offer** for modified, network-facing components (gromox, web, sync, dav, admin-api, admin-web): form of offer and scope. (groupware-source-eval §4)
6. **EU Cyber Resilience Act.** Do modified, distributed or hosted variants make us a manufacturer with reporting duties? (groupware-source-eval §12.5)
