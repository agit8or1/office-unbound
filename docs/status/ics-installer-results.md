## nspawn quirks hit
- New machines failed to boot: `Failed to create control group inotify object: Too many open files` (host `fs.inotify.max_user_instances=128` exhausted by the other lab machines + agents). Raised at runtime to 512 (`sysctl -w`, **not persistent**; see host-changes).
- `machinectl start` returns before the machine is usable; `systemd-run -M` says "Host is down" until boot finishes (poll). Clones keep hostname `ou-base`: set it with `hostnamectl` and fix `/etc/hosts`.
- `PrivateUsers=pick`: files placed from the host must be chowned to the machine's shifted root uid (stat of `<machine>/root`), else the machine sees them as nobody.
- nftables works inside a zone-networked machine (CAP_NET_ADMIN is granted with private networking): `ics-admin-fw` loaded without `--skip-firewall`.
- No `policy-rc.d` in the base image; the installer adds a temporary one so nginx never listens on :80 with the default site.
- Single-use TOTP: logging in right after enrolling with the same 30 s code is rejected, and repeated retries hit the login throttle (429; cleared with `ics.cli unlock`). The test client waits for the next step.

## Limits / not proven
- Package "pinning" is by Ubuntu release and package major version; exact versions are printed and not frozen (no apt snapshot). Python deps are hash-pinned.
- Not exercised: `--tls-cert/--tls-key`, certificate renewal near expiry, a connection from a source outside `--allow-cidr` (the nft/nginx rules are generated from the same list as on the lab host but not attacked from a denied address), IPv6, a never-before-seen apt mirror outage.
- The restore drill used the existing passive restore (`ics-restore-inner.sh`); cut-over of the front end onto the restored host (new IP => new CA) is still the manual runbook step. A restored host whose IP differs from the CA's constraints makes `bootstrap.sh` refuse (by design: a name-constrained CA cannot be widened).
- First fresh run took ~2 min on this host (apt + pip dominate). Evidence logs were kept in the agent scratchpad, not in the repo.
